ควบคุมจากมือถือ / เครื่องอื่น

ให้คอมเครื่องนี้เปิดทิ้งไว้ทำฟาร์ม แล้วเปิดหน้าควบคุมจากมือถือหรือคอมเครื่องอื่นได้ ต้องใส่รหัสผ่านทุกครั้งที่เข้าจากเครื่องอื่น

รหัสผ่าน (อย่างน้อย 6 ตัว)
เปิดที่มือถือ/เครื่องอื่น (ต่อ Wi-Fi เดียวกัน หรือผ่าน Tailscale)

วิธีตั้งค่า
  1. ตั้งรหัสผ่านแล้วเปิดสวิตช์ด้านบน ถ้า Windows ถามเรื่อง Firewall ให้กด อนุญาต (Allow) สำหรับเครือข่ายส่วนตัว
  2. อยู่บ้าน (Wi-Fi เดียวกัน): เปิดลิงก์ที่ขึ้นด้านบนในเบราว์เซอร์มือถือ แล้วใส่รหัสผ่าน
  3. อยู่นอกบ้าน: ลงแอป Tailscale (ฟรี) ทั้งในคอมเครื่องนี้และมือถือ ล็อกอินบัญชีเดียวกัน แล้วเปิดลิงก์ที่ขึ้นต้นด้วย 100.
  4. ตอนเปิดใช้งานอยู่ ปิดหน้าต่างนี้แล้วบอทยังทำงานต่อ จะเปิดหน้าต่างกลับมา ให้ดับเบิลคลิก CookieRunBot อีกครั้ง จะปิดโปรแกรมจริง ให้กด "ปิดโปรแกรม" ในหน้าเกี่ยวกับ
  5. ตั้งคอมไม่ให้ Sleep เอง (Settings → System → Power) และเปิดอีมูเลเตอร์ + เกมค้างไว้
